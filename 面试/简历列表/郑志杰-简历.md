### 京东稳定币（2024.02 - 2025.12）

> 京东稳定币是京东集团推出的港元锚定稳定币（类似 USDC 锚定美元），已获得<span style="color: blue">香港金管局沙盒准入、中东稳定币牌照、欧洲预牌照</span>。该项目为稳定币发行、交易、兑换提供完整的链下系统支撑，先后负责用户体系模块和 OpenAPI 支付接入模块的核心开发。
>
> 技术栈：Spring Boot / Spring Cloud Gateway / Dubbo RPC / MyBatis / Redis / Kafka / Apollo / OAuth2.0

**用户体系模块：**

- 主导设计多端多渠道注册登录体系：适配 App/Web 三端、邮箱/手机号/Google/Apple/Passkey 五类登录渠道，通过三方身份映射表实现注册登录二合一，Passkey 基于 WebAuthn 挑战-响应协议实现服务端零密码存储，认证时校验签名计数器防凭证重放，同设备重复注册时自动替换旧凭证。
- 负责凭证安全存储与多层登录防护的设计与开发：凭证存储采用 PBKDF2+RSA 双层加密（传输层 RSA 解密→存储层 PBKDF2 哈希），重置密码时校验历史密码防重复；登录防护采用分层策略——白名单放行、密码错误触发验证码、Redis 失败计数与凭证锁定、风控校验、新设备 OTP 二次确认，每层独立生效互不依赖。
- 负责 OAuth2.0 SSO 单点登录的设计与开发，支持 PKCE 安全扩展：基于 Redis 全局会话实现跨应用单点登录与统一登出，授权码一次性使用且绑定 clientId+scope+用户信息，PKCE 扩展防护授权码拦截攻击，实现 AccessToken/RefreshToken 双令牌机制与无感刷新。

**OpenAPI 支付接入模块：**

- 负责 API 网关安全体系设计与开发，针对开放接口面临的三类安全威胁（请求伪造、重复请求、数据泄露），设计请求-响应全链路安全防护：三层防重放机制（签名验签层防篡改、Nonce+Redis 分布式锁防重复、Timestamp 时效层防过期重放），并实现按接口维度限流；响应侧对接口响应体做 AES 对称加密，响应头做 RSA 签名，商户可通过签名验签确认响应未被篡改。
- 负责预下单、支付完成、退款、查询支付结果等核心交易接口开发，围绕资金安全设计了多层防护：预下单通过数据库唯一索引实现幂等防止重复下单；退款前校验链覆盖超退检查、退款余额充足性校验、清分未完成禁止退款、退款币种一致性校验、部分退款频率限制等，退款金额按原支付单汇率换汇后校验，防止汇率波动导致超退。
- 负责清结算模块开发，实现支付成功后的资金清分与指令下发：按合约维度归集清分单，通过 MDR 计费规则分发器计算商户实收与手续费（支付按固定费率、退款全额返还），生成清分指令并显式事务保证指令与清分单的原子性；针对清分指令卡在 Paying 中间态的场景，设计定时恢复任务，超时阈值触发异常登记，保障清分指令最终推进到终态。
